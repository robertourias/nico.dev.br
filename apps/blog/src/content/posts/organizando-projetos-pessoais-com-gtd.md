Ter dezenas de ideias e projetos pessoais é ótimo. Deixar todos parados por falta de organização não é.

## O problema

Side projects morrem não por falta de tempo — morrem por falta de próxima ação clara. Você abre o repositório, não sabe por onde começar, fecha.

## O que funciona pra mim

### Capture tudo

Toda ideia vai para uma inbox única (uso Notion). Não importa o tamanho — vai para lá. O objetivo é esvaziar a cabeça.

### Processe uma vez por semana

Toda segunda de manhã, processo a inbox:
- Lixo → deleta
- Referência → move para uma pasta de referência
- Ação futura → define a **próxima ação física** e coloca no backlog

A próxima ação deve ser específica: não "trabalhar no blog", mas "criar componente Header do blog".

### Revise projetos ativos

Limite de 3 projetos ativos simultaneamente. Se um novo projeto é mais importante, um ativo pausa.

## Ferramentas que uso

- Notion para captura e backlog
- GitHub Projects para tracking de código
- Bloco de notas físico para o dia seguinte

O segredo não está na ferramenta — está no hábito semanal.
