# Changelog — 2026-06-03

## packages/ui — Header Compound Components

Implementação completa do sistema de Header compartilhado entre todos os apps do monorepo.

### Novos componentes
- `Header` — root compound, `scrollAware` (transparente→frosted no scroll) e `borderColor` props
- `Header.Logo` — link de identidade do app
- `Header.Nav` — nav desktop (hidden mobile), aceita `className` para override de breakpoint
- `Header.Actions` — slot de ações à direita (ThemeToggle, LocaleSwitcher, social links)
- `Header.Menu` — side drawer móvel: híbrido controlled/uncontrolled, `side="left|right"`, body scroll lock, close-on-link-click, portal em `document.body` (escapa stacking context de `backdrop-filter`)
- `NavLink` — `href`, `external`, `active` props; tokens canônicos
- `ThemeToggle` — SSR-safe, `.dark` class toggle, `localStorage` persistência

### Fix crítico de UI
`Header.Menu` drawer renderizado via `createPortal(drawer, document.body)` — evita que `backdrop-filter: blur()` no header crie stacking context que coloca o drawer sob o conteúdo da página.
