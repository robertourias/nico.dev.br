# Changelog — 2026-06-08

## apps/metronome — melhorias de UI e novos features

### Layout e tamanhos
- Botões (-)(+) do Beats centralizados horizontalmente (layout `flex-col items-center`) e aumentados 20% (`w-[34px] h-[34px]`)
- BPM presets aumentados 30% (`h-7 px-2.5 text-xs` → `h-9 px-3.5 text-sm`)
- Timer presets migrados para `grid grid-cols-5 gap-2 h-10 rounded-lg` (mesmo padrão das subdivisions)

### Novos sons
- 2 novos sons adicionados: **Wood** (noise burst + filtro bandpass) e **Beep** (oscilador square)
- `SoundPicker` component criado acima dos beat indicators
- Preview ao clicar em cada opção; som selecionado é usado no metrônomo e nas subdivisões
- `lib/sounds.ts` define `SoundId`, `audio-engine.ts` expandido com `createWoodClick` / `createBeepClick`

### Toggles
- `StressFirstBeat` e `TimerControl`: `Checkbox` substituído por `Switch` (Toggle) de `@nico.dev/ui`

### Document Picture-in-Picture
- Botão fixo (desktop, `hidden md:flex`) no canto superior direito
- Janela flutuante com: BPM ±5, presets de BPM, beat dots animados, sound picker, timer countdown, Start/Stop
- `use-pip.ts` hook + `pip-content.tsx` component
- Type declarations em `src/types/document-picture-in-picture.d.ts`
- Bug de hydration corrigido: `isSupported` inicializado via `useEffect`
