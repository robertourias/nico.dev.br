# Changelog — 2026-06-04

## apps/tools — debug-code

- Migrado `@google/generative-ai` → `@google/genai@2.8.0`; API nova: `GoogleGenAI`, `ai.models.generateContent`, `response.text`
- Modelo alterado para `gemini-2.5-flash-lite`
- Split de erros na rota: `QUOTA_EXCEEDED` (429/RESOURCE_EXHAUSTED) e `GEMINI_API_ERROR` (demais falhas) com `console.error` do detalhe real
- Mensagem de erro de quota exibida na UI: "Limite de uso da API atingido. Aguarde alguns minutos e tente novamente."
- Badges de tipo de erro traduzidos para pt-BR (`SyntaxError` → "Erro de Sintaxe" etc.)
- Prompt da IA instrui resposta de `message` e `fix` em pt-BR

## apps/tools — página inicial

- Cards "Em breve" recebem `className="bg-muted"` para visual mais escuro que cards ativos

## apps/metronome — Wake Lock API

- Novo hook `src/hooks/use-wake-lock.ts`: solicita `navigator.wakeLock.request('screen')` quando `isActive=true`, libera ao desativar, reativa em `visibilitychange`, guard de concorrência via `isAcquiringRef`, silent no-op em browsers sem suporte, Strict Mode compatível
- `useMetronome` integra `useWakeLock(isPlaying)` sem alteração da interface pública
